# Simple Interest Calculator

This project provides a simple Bash script to calculate simple interest based on user input.

## Features

- Calculates simple interest
- Accepts principal amount from the user
- Accepts rate of interest from the user
- Accepts time period from the user
- Displays the calculated simple interest

## Formula

Simple Interest = (Principal × Rate × Time) / 100

- `simple-interest.sh` – Bash script to calculate simple interest.

## How to Run

1. Clone the repository.

```bash
git clone https://github.com/<your-username>/simple-interest-calculator.git
```

2. Move into the project directory.

```bash
cd simple-interest-calculator
```

3. Make the script executable.

```bash
chmod +x simple-interest.sh
```

4. Run the script.

```bash
./simple-interest.sh
```

## Example

```
Enter Principal:
10000
Enter Rate of Interest:
5
Enter Time (years):
2

Simple Interest = 1000
```
